# Accessibility report

> **Doc type:** Living reference — draft (JavaFX handoff stage 2; contrast only so far). Last reviewed: 2026-10-09.

This report records the authoritative accessibility checks of the design system on the repository's token values, replacing the indicative figures Claude Design computed in its web previews. It covers the floors of R-UI-17: text at least 4.5:1 (7:1 in high contrast), state indicators, focus rings and other marks at least 3:1, in every theme.

| Check | Status |
|---|---|
| Contrast of every declared pairing and the derived checks of the JavaFX handoff §7 | run 2026-10-09: no failure (results below) |
| Colour-vision deficiency (Machado 2009 with a Brettel/Viénot/Mollon cross-check, CIEDE2000) | not run – stage 4 of the JavaFX handoff |
| Contrast on the rendered JavaFX sheets | not run – the sheets are written in stage 3; Modena is replaced (ADR-0004), so there are no Modena-derived colours to reproduce |
| Manual protocol (keyboard, focus, 200 % text, scales, reduced motion, high contrast, screen reader, glyphs, greyscale) | not run – stage 4 |

**Scope of the contrast run.** Every pairing the system declares (575), plus derived checks:
- the focus ring on every surface, deviation background, selection tint and hover tint;
- every confidence border on every deviation background, the selection tint and the hover tint;
- the major-deviation Δ badge;
- the focus ring on the primary and the danger fill;
- the three text colours on every surface and state ground;
- the dark theme's luminance band.

Re-run it with `java tools/design-system/Contrast.java ui/design-tokens docs/design-system/accessibility-report.md "<inputs>"`; the script replaces the section below.
