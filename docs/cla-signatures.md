# UEX Datarunner Client — CLA signatures

> **Doc type:** Living reference — current. Last reviewed: 2026-10-08.

This file is the public roster of Contributors who have signed the
[UEX Datarunner Client Individual Contributor Licence Agreement](../CLA.md).

If You are signing for the first time, follow the procedure in
[§ 11 of the CLA](../CLA.md#11-how-to-sign): open a pull request titled
`cla: sign — <your-github-handle>` that appends a row to the table
below, and include the verbatim acceptance sentence from § 11 in the
pull-request description.

The table is intentionally minimal — Your full legal name, Your GitHub
handle, the e-mail address You use for Git commits (Your GitHub
noreply address is accepted if You commit with it), the date You signed
in ISO-8601 format, and the CLA version You signed. Do not include
postal addresses, phone numbers, or any other personal data. This file
is public, and every row stays in the repository's history.
