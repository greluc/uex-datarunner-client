# Triage labels

> **Doc type:** Living reference — current. Last reviewed: 2026-10-13.

The skills speak in terms of five canonical triage roles. This file maps those roles to the label strings used in this repository's issue tracker. The strings are the defaults; all five exist on GitHub.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

The wayfinder labels `wayfinder:map`, `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling` and `wayfinder:task` also exist. Applying or changing labels on an issue is a GitHub write and needs @greluc's yes ([`issue-tracker.md`](issue-tracker.md)).
